FlowEngine — Core Schema Reference

Reference for ExecutionInstance, IExecutionStateStore, and the foundational interfaces used by the runtime and provider packages.

ExecutionInstance + IExecutionStateStore

This document describes the foundational runtime types and interfaces used by
node executors, state store implementations, and engine services. Changes in
this area affect cross-package compatibility.

1. ExecutionInstance

csharp// Source: EF.FlowEngine/Model/ExecutionInstance.cs

/// <summary>
/// The root state object for a single workflow execution.
/// Every property is persisted by <see cref="IExecutionStateStore"/> and
/// read/written by the engine loop and node executors.
/// </summary>
/// <remarks>
/// <para>
/// <c>ExecutionInstance</c> is the primary aggregate root in the FlowEngine domain.
/// Key state groups:
/// <list type="bullet">
///   <item><c>Status + CurrentNodeId</c> - current position in the workflow graph.</item>
///   <item><c>PendingWait + PendingHumanTaskId</c> - suspension point awaiting an external signal.</item>
///   <item><c>Context</c> - mutable JSONPath-addressable dictionary accumulated across all nodes.</item>
///   <item><c>History</c> - ordered, immutable audit trail of every node execution.</item>
///   <item><c>ClaimedBy + ClaimedAt + ClaimExpiresAt</c> - distributed execution lease.</item>
///   <item><c>Version</c> - monotonically-incrementing optimistic concurrency counter.</item>
/// </list>
/// </para>
/// <para>
/// Typical state transitions:
/// <code>
/// Queued -> Running -> Suspended (wait node) -> Running -> Completed
///   (intake queue)    (external signal via ResumeAsync)
/// Running -> Faulted  (unhandled error, no recovery path)
/// Running -> Cancelled (explicit CancelAsync)
/// Running -> TimedOut  (Deadline exceeded)
/// </code>
/// </para>
/// <para>
/// Persistence: saved by <see cref="IExecutionStateStore"/> when the instance suspends or ends, at checkpoint
/// nodes, before a failure unwind, and after every node when the definition sets PersistAfterEveryNode;
/// locks managed by <see cref="IDistributedLockProvider"/> to prevent duplicate execution.
/// Outbox entries are saved with the state through <see cref="IExecutionStateStore.SaveWithOutboxAsync"/>, atomically
/// only when the store overrides it (the default saves state, then enqueues the entries).
/// </para>
/// </remarks>
public sealed class ExecutionInstance
{
    // ── Identity ──────────────────────────────────────────────────────────────

    /// <summary>Globally unique identifier for this execution instance (GUID, no hyphens).</summary>
    public string InstanceId { get; init; } = string.Empty;

    /// <summary>The ID of the workflow definition being executed.</summary>
    public string WorkflowId { get; init; } = string.Empty;

    /// <summary>Optional tenant identifier for multi-tenant deployments. Propagated from <see cref="StartRequest.TenantId"/>.</summary>
    public string? TenantId { get; init; }

    /// <summary>The specific version of the workflow definition that was resolved at start time. Mutable to support explicit version migration via <c>IFlowEngine.MigrateInstanceAsync</c>.</summary>
    public string WorkflowVersion { get; set; } = string.Empty;

    /// <summary>Optional external correlation ID for deduplication, tracing, or linking to domain objects.</summary>
    public string? CorrelationId { get; init; }

    /// <summary>ID of the parent instance when this is a child spawned by a loop, parallel, or workflow node.</summary>
    public string? ParentInstanceId { get; init; }

    /// <summary>Node ID in the parent workflow that spawned this instance.</summary>
    public string? ParentNodeId { get; init; }

    // ── Status ────────────────────────────────────────────────────────────────

    /// <summary>The current lifecycle status of this instance.</summary>
    public ExecStatus Status { get; set; }

    /// <summary>The ID of the node currently being executed (or the last executed node when suspended/terminal).</summary>
    public string CurrentNodeId { get; set; } = string.Empty;

    /// <summary>Tracks how many times each node has been visited to enforce <c>MaxVisits</c> cycle detection.</summary>
    public Dictionary<string, int> NodeVisitCounts { get; set; } = new();

    // ── Timing ────────────────────────────────────────────────────────────────

    /// <summary>UTC timestamp when the instance was created.</summary>
    public DateTimeOffset CreatedAt { get; init; }

    /// <summary>UTC timestamp of the last state change.</summary>
    public DateTimeOffset UpdatedAt { get; set; }

    /// <summary>UTC timestamp when the instance reached a terminal state, or <c>null</c> if still active.</summary>
    public DateTimeOffset? CompletedAt { get; set; }

    /// <summary>
    /// Optional hard deadline for the entire instance, enforced while it runs and while it is suspended (a wait's
    /// timeout is capped at it until it is handled). When exceeded, the engine routes to
    /// <c>GlobalOnDeadlineNodeId</c>, or without one unwinds a saga (when compensation is enabled) and sets status to
    /// <see cref="ExecStatus.TimedOut"/>.
    /// </summary>
    public DateTimeOffset? Deadline { get; init; }

    /// <summary>
    /// UTC timestamp when the engine handled the passed <see cref="Deadline"/>: routed to
    /// <c>GlobalOnDeadlineNodeId</c>, or ended the instance <see cref="ExecStatus.TimedOut"/>. <c>null</c> until then.
    /// Once set, the deadline is not enforced again, so a suspended deadline handler continues when resumed.
    /// </summary>
    public DateTimeOffset? DeadlineHandledAt { get; set; }

    /// <summary>
    /// UTC timestamp when execution was first routed to <c>GlobalOnDeadlineNodeId</c>, by the passed
    /// <see cref="Deadline"/> or by a wait timeout without an <c>OnTimeoutNodeId</c> falling back to it. The handler
    /// runs at most once per instance: once set, neither routes to it again. Does not stop deadline enforcement: a
    /// deadline that passes while a handler entered by a wait-timeout fallback still runs ends the instance
    /// <see cref="ExecStatus.TimedOut"/>.
    /// </summary>
    public DateTimeOffset? DeadlineHandlerEnteredAt { get; set; }

    // ── Context ───────────────────────────────────────────────────────────────

    /// <summary>
    /// The mutable workflow context containing the entity, params, and all context values
    /// accumulated during execution.
    /// </summary>
    public ContextDictionary Context { get; set; } = new();

    // ── Async / Wait ──────────────────────────────────────────────────────────

    /// <summary>Describes the event the instance is waiting for when <see cref="Status"/> is <see cref="ExecStatus.Suspended"/>.</summary>
    public WaitDescriptor? PendingWait { get; set; }

    /// <summary>The ID of the human task the instance is waiting for, when suspended at a human node.</summary>
    public string? PendingHumanTaskId { get; set; }

    // ── Output / Error ────────────────────────────────────────────────────────

    /// <summary>The final output produced by the workflow when it completes successfully.</summary>
    public ContextValue? Output { get; set; }

    /// <summary>Error details for a terminal outcome, or a pending resume fault awaiting execution admission.</summary>
    public ExecutionError? Error { get; set; }

    // ── Observability ─────────────────────────────────────────────────────────

    /// <summary>Key/value tags for filtering, routing, and observability dashboards.</summary>
    public Dictionary<string, string> Tags { get; set; } = new();

    /// <summary>Ordered list of node execution records providing a full audit trail.</summary>
    public List<NodeExecutionRecord> History { get; set; } = new();

    /// <summary>
    /// W3C <c>traceparent</c> string captured at the moment the instance suspends.
    /// Used by <c>ActivitySourceFlowEngineTelemetry</c> to link the resumed execution span
    /// back to the originating trace across async boundaries (e.g. resume from a separate HTTP call).
    /// <c>null</c> when the engine was started without OpenTelemetry activity tracking.
    /// </summary>
    public string? TraceContext { get; set; }

    // ── Distributed Execution ─────────────────────────────────────────────────

    /// <summary>The claimant ID of the engine node currently holding the execution lock, or <c>null</c> when unclaimed.</summary>
    public string? ClaimedBy { get; set; }

    /// <summary>UTC timestamp when the current lease was acquired.</summary>
    public DateTimeOffset? ClaimedAt { get; set; }

    /// <summary>UTC timestamp when the current lease expires; used by the sweep service to detect crashed engines.</summary>
    public DateTimeOffset? ClaimExpiresAt { get; set; }

    // ── Optimistic Concurrency ────────────────────────────────────────────────

    /// <summary>
    /// Monotonically-incrementing version counter used for optimistic concurrency.
    /// Implementations of <see cref="IExecutionStateStore.SaveAsync"/> should reject saves
    /// where the stored version is higher than this value.
    /// </summary>
    public long Version { get; set; } = 0;

    /// <summary>
    /// Creates a shallow, field-by-field copy of this instance. Reference-typed members
    /// (<see cref="Context"/>, <see cref="History"/>, <see cref="Tags"/>, <see cref="PendingWait"/>, ...)
    /// are shared with the original, so the copy is intended for read-only previews
    /// (e.g. a dry-run migration result) rather than independent mutation. Callers that need to
    /// mutate a reference member on the copy must replace that member with a fresh collection first.
    /// </summary>
    internal ExecutionInstance ShallowCopy() => (ExecutionInstance)MemberwiseClone();

    /// <summary>
    /// A copy for a caller that must not see later changes: a background execution keeps mutating the original.
    /// The collections an execution changes are copied; their elements are shared. Context values and signal
    /// payloads are immutable; a history record's <c>BranchTaken</c> is set only while its node is being
    /// recorded, so take the snapshot before the execution starts. Does not serialize, so it does not fail on
    /// context value types the engine's JSON contract does not know.
    /// </summary>
    internal ExecutionInstance Snapshot()
    {
        var copy = ShallowCopy();
        copy.Context = new ContextDictionary
        {
            Entity = Context.Entity,
            Params = Context.Params is null ? null : new(Context.Params, Context.Params.Comparer),
            Context = new(Context.Context, Context.Context.Comparer)
        };
        copy.NodeVisitCounts = new(NodeVisitCounts, NodeVisitCounts.Comparer);
        copy.Tags = new(Tags, Tags.Comparer);
        copy.History = [.. History];
        copy.PendingWait = PendingWait?.Copy();
        return copy;
    }
}

2. ExecStatus

csharp// Source: EF.FlowEngine/Model/ExecStatus.cs

/// <summary>Lifecycle status of a workflow execution instance.</summary>
public enum ExecStatus
{
    /// <summary>
    /// The instance has been submitted and persisted but is waiting for an intake queue slot
    /// before execution begins. Only set when an <c>IIntakeQueue</c> is registered.
    /// The intake drain service transitions queued instances to <see cref="Running"/>.
    /// </summary>
    Queued,

    /// <summary>The instance is actively executing on an engine node.</summary>
    Running,

    /// <summary>The instance is paused waiting for an external event (wait, timer, human, or message reply).</summary>
    Suspended,

    /// <summary>The instance has run to completion successfully.</summary>
    Completed,

    /// <summary>
    /// The instance terminated due to an unhandled error. Its open human tasks are cancelled; its children keep running,
    /// as a dead-letter replay of the failed node adopts them.
    /// </summary>
    Faulted,

    /// <summary>The instance was explicitly cancelled via <see cref="IFlowEngine.CancelAsync"/>.</summary>
    Cancelled,

    /// <summary>
    /// The instance exceeded its configured <see cref="ExecutionInstance.Deadline"/> or a wait timeout. Its open human
    /// tasks and non-terminal children are cancelled.
    /// </summary>
    TimedOut,

    /// <summary>
    /// A node exceeded its <c>MaxVisits</c> limit, indicating an infinite loop in the definition. Its open human tasks
    /// and non-terminal children are cancelled.
    /// </summary>
    CycleDetected
}

ExecStatus state transition diagram

StartAsync                     -> Running (saved, then executed inline; the intake queue is not used)
StartBackgroundAsync
   |-- IIntakeQueue registered -> Queued
   '-- otherwise               -> Running

Valid transitions:
  Queued    -> Running       (IntakeDrainService drains the queued instance)
  Queued    -> Cancelled     (CancelAsync)
  Running   -> Suspended     (wait / timer / human / message-reply node, or an open circuit with no CircuitOpen edge)
  Running   -> Completed     (output node, or a node without edges finishing without Error/CircuitOpen)
  Running   -> Faulted       (failure with no Error edge and no GlobalOnFailureNodeId, after any saga unwind;
                              a node without edges faults with its own error code)
  Running   -> TimedOut      (instance Deadline passed with no GlobalOnDeadlineNodeId, after any saga unwind)
  Running   -> CycleDetected (execution loop: a node exceeded MaxVisits; set only by this guard)
  Running   -> Cancelled     (CancelAsync)
  Suspended -> Running       (ResumeAsync / human task response / child completion / sweep:
                              timer elapsed, signals accumulated, wait timeout routed, expired claim)
  Suspended -> Cancelled     (CancelAsync)
  Suspended -> Running -> TimedOut
                             (deadline or unhandled wait timeout found by the sweep; the saga unwinds in the
                              execution loop first, then the instance ends TimedOut)

Deadline (also enforced while Suspended):
  GlobalOnDeadlineNodeId set and not yet entered -> execution continues at that node
  otherwise                                      -> saga unwind, then TimedOut (INSTANCE_DEADLINE_EXCEEDED)

Wait timeout (PendingWait.TimeoutAt reached):
  timer node           -> resumed with Match (the delay was the intent)
  wait with onTimeout  -> routed to OnTimeoutNodeId
  else                 -> GlobalOnDeadlineNodeId (unless DeadlineHandlerEnteredAt is set),
                          else WAIT_TIMEOUT: saga unwind, then TimedOut

Terminal states (no further transitions):
  Completed, Faulted, Cancelled, TimedOut, CycleDetected

## 3. ContextValue — discriminated union

```csharp
/// <summary>
/// A value in the execution context. Supports all types nodes can
/// produce or consume. Serializes cleanly to/from JSON for state
/// store persistence.
/// </summary>
[JsonPolymorphic(TypeDiscriminatorPropertyName = "$type")]
[JsonDerivedType(typeof(JsonContextValue),     "json")]
[JsonDerivedType(typeof(DocumentContextValue), "document")]
[JsonDerivedType(typeof(NullContextValue),     "null")]
public abstract class ContextValue { }

/// <summary>JSON-serializable scalar or object value.</summary>
public sealed class JsonContextValue : ContextValue
{
    public JsonElement Value { get; init; }
}

/// <summary>
/// Reference to a binary document (PDF, DOCX, image, etc.) stored
/// externally. The engine passes the reference through context without
/// loading the bytes. Nodes that need the content resolve it via
/// IDocumentStore.
/// </summary>
public sealed class DocumentContextValue : ContextValue
{
    /// <summary>Opaque reference into the document store (URL, blob path, etc.).</summary>
    public string   StoreRef    { get; init; }
    public string   FileName    { get; init; }
    public string   ContentType { get; init; }
    public long     SizeBytes   { get; init; }
    public DateTimeOffset StoredAt { get; init; }
}

/// <summary>Explicit null — distinguishable from absent key.</summary>
public sealed class NullContextValue : ContextValue { }

/// <summary>
/// The top-level context container. Provides typed access to the three
/// reserved namespaces and the mutable context dictionary.
/// </summary>
public sealed class ContextDictionary
{
    public ContextValue?                     Entity  { get; set; }  // $.entity
    public Dictionary<string, ContextValue>? Params  { get; set; }  // $.params
    public Dictionary<string, ContextValue>  Context { get; set; } = new(); // $.context

    // ── $.engine namespace note ──────────────────────────────────────────────
    // The $.engine.* namespace is NOT stored in this dictionary.
    // It is synthesised at resolution time by the concrete IExecutionContext
    // implementation from the live ExecutionInstance fields (NodeVisitCounts,
    // Status, etc.). It is read-only and cannot be written via Store().
    //
    // Paths handled by IExecutionContext.Resolve() dispatcher:
    //   $.entity        → this.Entity
    //   $.params.x      → this.Params["x"]
    //   $.context.x     → this.Context["x"]
    //   $.engine.*      → synthesised (never stored here)

    /// <summary>
    /// Resolve a JSONPath expression against this context.
    /// Supports $.entity, $.params.x, $.context.x
    /// Returns null if path not found.
    /// NOTE: $.engine.* paths are NOT resolved here — they are resolved
    /// by the concrete IExecutionContext.Resolve() implementation which
    /// has access to the live ExecutionInstance. This method handles only
    /// the three stored namespaces.
    /// </summary>
    public ContextValue? Resolve(string jsonPath)
    {
        // Concrete implementation — not a placeholder.
        // Parses namespace prefix and dispatches to Entity, Params, or Context dict.
        // See IExecutionContext in section 18 for the full resolver including $.engine.
        throw new NotSupportedException(
            "ContextDictionary.Resolve is a stub for documentation. " +
            "Use IExecutionContext.Resolve() from node executors.");
    }

    /// <summary>Write a value to $.context[key].</summary>
    public void Store(string key, ContextValue value) => Context[key] = value;
}

4. WaitDescriptor

csharp// Source: EF.FlowEngine/Model/WaitDescriptor.cs

/// <summary>
/// Describes the suspension state of a workflow instance waiting for an external event.
/// Stored on <see cref="ExecutionInstance.PendingWait"/> when the instance is
/// <see cref="ExecStatus.Suspended"/>.
/// </summary>
/// <remarks>
/// <para>
/// Created by the <c>wait</c>, <c>timer</c>, <c>human</c>, and <c>message</c> node executors.
/// The engine sweep service (<c>ExecutionSweepService</c>) polls for timed-out waits by checking
/// <see cref="TimeoutAt"/> against the current clock and calls
/// <see cref="IFlowEngine.ResumeByInstanceIdAsync"/> to resume timed-out instances.
/// </para>
/// <para>
/// A wait is matched for resume by (<c>EventName</c>, <c>CorrelationKey</c>) pair via
/// <see cref="IExecutionStateStore.FindBySuspendedEventAsync"/>.
/// When <see cref="MinSignalCount"/> &gt; 1, signals accumulate in <see cref="ReceivedSignals"/>
/// and the instance resumes only once the threshold is reached.
/// </para>
/// <seealso cref="IFlowEngine.ResumeAsync"/>
/// <seealso cref="ExecutionInstance.PendingWait"/>
/// </remarks>
public sealed class WaitDescriptor
{
    /// <summary>The logical event name the instance is waiting for (matched against the <c>eventName</c> parameter of <c>ResumeAsync</c>).</summary>
    public string EventName { get; init; } = string.Empty;

    /// <summary>
    /// The correlation key that uniquely scopes this wait within the event type.
    /// Typically derived from the entity ID or an external reference.
    /// </summary>
    public string CorrelationKey { get; init; } = string.Empty;

    /// <summary>
    /// Optional deadline after which the wait times out. Evaluated by the sweep service. While the instance
    /// <see cref="ExecutionInstance.Deadline"/> is unhandled the engine caps it at that deadline (a wait without a
    /// timeout gets the deadline), so the sweep enforces the deadline on a suspended instance.
    /// </summary>
    public DateTimeOffset? TimeoutAt { get; init; }

    /// <summary>
    /// The node to jump to when a timeout occurs. When <c>null</c>, the timeout falls back to the workflow's
    /// <c>GlobalOnDeadlineNodeId</c> while that handler has not been entered; otherwise the instance ends
    /// <see cref="ExecStatus.TimedOut"/> with <c>WAIT_TIMEOUT</c> (with compensation enabled, the saga unwinds first).
    /// </summary>
    public string? OnTimeoutNodeId { get; init; }

    /// <summary>
    /// The minimum number of signals that must be received before the instance resumes.
    /// Enables multi-signal aggregation (e.g. wait for N approvals). Default: 1.
    /// </summary>
    public int MinSignalCount { get; init; } = 1;

    /// <summary>Accumulated signal payloads received so far; the instance resumes when count reaches <see cref="MinSignalCount"/>.</summary>
    public List<JsonElement> ReceivedSignals { get; set; } = new();

    /// <summary>A copy with its own <see cref="ReceivedSignals"/> list.</summary>
    internal WaitDescriptor Copy()
    {
        var copy = (WaitDescriptor)MemberwiseClone();
        copy.ReceivedSignals = [.. ReceivedSignals];
        return copy;
    }

    /// <summary>
    /// Whether the most recently accumulated signal included a payload. False preserves payload-free
    /// resume semantics during sweep recovery; null denotes legacy records without this information.
    /// </summary>
    public bool? LastSignalHasPayload { get; set; }
}

5. NodeExecutionRecord

csharp// Source: EF.FlowEngine/Model/NodeExecutionRecord.cs

/// <summary>
/// An immutable record of a single node execution appended to
/// <see cref="ExecutionInstance.History"/>. Provides a full audit trail of
/// every step taken by the workflow.
/// </summary>
public sealed class NodeExecutionRecord
{
    /// <summary>The unique identifier of the node that was executed.</summary>
    public string NodeId { get; init; } = string.Empty;

    /// <summary>
    /// The node type discriminator (e.g. <c>"fetch"</c>, <c>"decision"</c>). <c>"migration"</c> is reserved: it marks
    /// the record a migration appends (not a run of the node), which saga compensation skips.
    /// </summary>
    public string NodeType { get; init; } = string.Empty;

    /// <summary>The human-readable label of the node at the time of execution.</summary>
    public string NodeLabel { get; init; } = string.Empty;

    /// <summary>UTC timestamp when execution of this node started.</summary>
    public DateTimeOffset StartedAt { get; init; }

    /// <summary>UTC timestamp when execution of this node finished, or <c>null</c> if still in progress.</summary>
    public DateTimeOffset? CompletedAt { get; init; }

    /// <summary>The outcome that drove edge selection after this node completed.</summary>
    public DecisionOutcome Outcome { get; init; }

    /// <summary>The label of the outgoing edge that was taken, or <c>"suspended"</c> if the instance suspended.</summary>
    public string? BranchTaken { get; set; }

    /// <summary>The context key under which the node's output was stored, or <c>null</c> if no <c>StoreAs</c> was set.</summary>
    public string? StoredAs { get; init; }

    /// <summary>Snapshot of the output value at the time of execution (for diagnostics).</summary>
    public ContextValue? OutputSnapshot { get; init; }

    /// <summary>HTTP status code from a fetch/integration call, included for tracing and retry decisions.</summary>
    public int? HttpStatusCode { get; init; }

    /// <summary>The 1-based attempt number, incremented by the retry handler on each retry.</summary>
    public int AttemptNumber { get; init; } = 1;

    /// <summary>Error details if the node produced an <see cref="DecisionOutcome.Error"/> outcome.</summary>
    public ExecutionError? Error { get; init; }

    /// <summary>
    /// When non-null this record represents a compensation step. The value is the
    /// <see cref="NodeId"/> of the original forward node being rolled back.
    /// Used by the engine to avoid double-compensating a step that was already rolled back.
    /// </summary>
    public string? CompensatingFor { get; init; }

    /// <summary>
    /// Optional free-form metadata set by specialised executors (e.g. agent nodes).
    /// Carries extra observability data such as <c>promptVersion</c>, <c>modelName</c>, <c>tokensUsed</c>.
    /// On a migration record, the engine sets <c>migratedFromNodeId</c>.
    /// </summary>
    public Dictionary<string, string>? Metadata { get; init; }

    /// <summary>Wall-clock duration of this node execution. Returns <see cref="TimeSpan.Zero"/> if <see cref="CompletedAt"/> is not set.</summary>
    public TimeSpan Duration => CompletedAt.HasValue
        ? CompletedAt.Value - StartedAt
        : TimeSpan.Zero;
}

6. DecisionOutcome

csharp// Source: EF.FlowEngine/Model/DecisionOutcome.cs

/// <summary>
/// Represents the result of a node execution, used by the engine to select
/// outgoing edges and drive retry/fault behaviour.
/// </summary>
public enum DecisionOutcome
{
    /// <summary>The node's condition was met or the operation succeeded.</summary>
    Match,

    /// <summary>The condition was explicitly not met (e.g. a null value, a filter that excluded the entity).</summary>
    NoMatch,

    /// <summary>The result is indeterminate (e.g. the path could not be resolved).</summary>
    Unknown,

    /// <summary>The node encountered an error; may trigger the retry policy or global failure handler.</summary>
    Error,

    /// <summary>Catch-all edge outcome used when no other outcome matches.</summary>
    Default,

    /// <summary>The circuit for this node's executor is open: the engine did not call the executor, or the executor reported its dependency's own circuit open. An executor returning it asserts it caused no side effects: such a visit is not compensated. It is recorded as a circuit failure when the node has a circuit breaker policy, except for compensation steps and the global failure and deadline handler nodes, which run past circuits without recording on them. Routes to a <c>CircuitOpen</c> edge if present, otherwise suspends the instance until the circuit cools down.</summary>
    CircuitOpen
}

/// <summary>Well-known context keys written to the workflow context when a human task completes.</summary>
public static class HumanTaskContextKeys
{
    /// <summary>Context key holding the most recent <see cref="HumanTaskResponse"/> values as JSON.</summary>
    public const string Response = "_humanTaskResponse";

    /// <summary>Context key holding the list of all collected responses.</summary>
    public const string Responses = "_humanTaskResponses";

    /// <summary>Context key holding the consensus label computed from quorum responses (e.g. <c>"unanimous"</c>, <c>"majority"</c>).</summary>
    public const string Consensus = "_humanTaskConsensus";

    /// <summary>
    /// Builds the resume payload a human task store passes to the engine when a task reaches its quorum: the task id
    /// under <c>_humanTaskId</c> correlates the response to the instance's pending task, the first
    /// response under <see cref="Response"/>, every response under <see cref="Responses"/>, and the consensus label
    /// (null for a single-respondent task) under <see cref="Consensus"/>.
    /// </summary>
    /// <param name="task">The completed task; it holds at least one response.</param>
    /// <returns>The signal payload the engine promotes into the instance context on resume.</returns>
    public static JsonElement BuildSignalPayload(HumanTask task)
    {
        var first = task.Responses[0].Values;

        if (task.Quorum <= 1)
        {
            return JsonSerializer.SerializeToElement(new
            {
                _humanTaskId = task.TaskId,
                _humanTaskResponse = first,
                _humanTaskResponses = task.Responses.Select(r => r.Values).ToArray(),
                _humanTaskConsensus = (string?)null
            });
        }

        // Multi-respondent: compute consensus label from all responses
        var consensusLabel = ComputeConsensusLabel(task.Responses);
        return JsonSerializer.SerializeToElement(new
        {
            _humanTaskId = task.TaskId,
            _humanTaskResponse = first,
            _humanTaskResponses = task.Responses.Select(r => r.Values).ToArray(),
            _humanTaskConsensus = consensusLabel
        });
    }

    /// <summary>
    /// Returns a consensus label for multi-respondent tasks:
    /// "unanimous" - all responses are identical,
    /// "any-denied" - majority rejected/denied/no,
    /// "majority" - more than half agree,
    /// "split" - no majority.
    /// </summary>
    private static string ComputeConsensusLabel(IReadOnlyList<HumanTaskResponse> responses)
    {
        if (responses.Count <= 1) return "unanimous";

        var groups = responses
            .GroupBy(r => r.Values.GetRawText())
            .OrderByDescending(g => g.Count())
            .ToList();

        if (groups.Count == 1) return "unanimous";

        var top = groups[0];

        // Majority: strictly more than half
        if (top.Count() > responses.Count / 2.0)
        {
            // Check if the majority answer contains a denial-like value
            var topJson = JsonDocument.Parse(top.Key).RootElement;
            var hasDenial = topJson.ValueKind == JsonValueKind.Object
                && topJson.EnumerateObject().Any(p =>
                    IsDenialValue(p.Value.ValueKind == JsonValueKind.String
                        ? p.Value.GetString()
                        : null));

            return hasDenial ? "any-denied" : "majority";
        }

        // Check if ANY response contains a denial
        var anyDenied = responses.Any(r =>
            r.Values.ValueKind == JsonValueKind.Object
            && r.Values.EnumerateObject().Any(p =>
                IsDenialValue(p.Value.ValueKind == JsonValueKind.String
                    ? p.Value.GetString()
                    : null)));

        return anyDenied ? "any-denied" : "split";
    }

    private static bool IsDenialValue(string? value)
        => value != null && (
            value.Equals("rejected", StringComparison.OrdinalIgnoreCase)
            || value.Equals("reject", StringComparison.OrdinalIgnoreCase)
            || value.Equals("denied", StringComparison.OrdinalIgnoreCase)
            || value.Equals("deny", StringComparison.OrdinalIgnoreCase)
            || value.Equals("no", StringComparison.OrdinalIgnoreCase)
            || value.Equals("false", StringComparison.OrdinalIgnoreCase));
}

10. IDistributedLockProvider

csharp// Source: EF.FlowEngine/Abstractions/IDistributedLockProvider.cs

/// <summary>
/// Provides distributed mutual exclusion for workflow execution instances.
/// Ensures that only one engine node executes a given instance at a time,
/// even across horizontally-scaled deployments.
/// Implement this interface using Redis, SQL, Azure Blob leases, or any other
/// distributed coordination mechanism.
/// </summary>
/// <remarks>
/// <para><b>Exclusivity.</b> Each successful <see cref="TryAcquireAsync"/> is exclusive: while an unexpired
/// lease exists, every further <see cref="TryAcquireAsync"/> returns <c>false</c>, including one from the claimant
/// that holds it. The engine uses one claimant id per process, so a re-entrant grant would let two code paths in
/// the same process (for example a start and the sweep) execute one instance concurrently. A holder that wants to
/// keep its lease calls <see cref="RenewAsync"/>.</para>
/// <para><b>Claim lifecycle.</b></para>
/// <list type="bullet">
/// <item><description>Start: <c>StartAsync</c> and <c>StartBackgroundAsync</c> take the lease with
/// <see cref="TryAcquireNewAsync"/> before the instance's first save, and save the record with
/// <c>ClaimedBy</c>/<c>ClaimExpiresAt</c> already set. The sweep therefore never sees a new Running instance
/// without a claim. Draining a Queued instance takes the lease before the record turns Running.</description></item>
/// <item><description>Execution: the engine loop confirms a lease taken at start with <see cref="RenewAsync"/>;
/// every other entry (signal resume, human-task resume, child completion, dead-letter replay, sweep) acquires with
/// <see cref="TryAcquireAsync"/> and skips the instance when that returns <c>false</c>. The lease is renewed by
/// <c>LeaseRenewalService</c> while the instance executes; a failed renewal cancels the execution.</description></item>
/// <item><description>Suspend and finish: when the instance suspends or reaches a terminal status, the engine
/// clears the claim fields, saves the record, then calls <see cref="ReleaseAsync"/>. Resuming a suspended instance
/// acquires a new lease.</description></item>
/// <item><description>Host shutdown: the instance stays Running and the lease is not released; once it expires
/// the sweep (<see cref="FindResumableInstanceIdsAsync"/>) resumes the instance on any node.</description></item>
/// <item><description>Cancel: <c>CancelAsync</c> tries to take the lease and proceeds without it when the instance is
/// executing; it releases only a lease it acquired.</description></item>
/// </list>
/// </remarks>
public interface IDistributedLockProvider
{
    /// <summary>
    /// Attempts to acquire an exclusive lease on the execution instance.
    /// Returns <c>true</c> when the lease is obtained; <c>false</c> while any unexpired lease exists,
    /// even one held by <paramref name="claimantId"/>.
    /// </summary>
    /// <param name="instanceId">The workflow execution instance to lock.</param>
    /// <param name="claimantId">Unique identifier for this engine node/process.</param>
    /// <param name="leaseDuration">How long the lease remains valid without renewal.</param>
    /// <param name="ct">Cancellation token.</param>
    Task<bool> TryAcquireAsync(
        string instanceId,
        string claimantId,
        TimeSpan leaseDuration,
        CancellationToken ct = default);

    /// <summary>
    /// Acquires the lease on a brand-new instance before the engine first saves it. The engine then saves the
    /// record with <c>ClaimedBy</c>, <c>ClaimedAt</c> and <c>ClaimExpiresAt</c> already set to this claim.
    /// The default calls <see cref="TryAcquireAsync"/>. A provider that keeps the lease on the instance record
    /// itself returns <c>true</c> without writing: the engine's first save is the acquisition.
    /// </summary>
    /// <param name="instanceId">The new instance's id; no record exists for it yet.</param>
    /// <param name="claimantId">Unique identifier for this engine node/process.</param>
    /// <param name="leaseDuration">How long the lease remains valid without renewal.</param>
    /// <param name="ct">Cancellation token.</param>
    Task<bool> TryAcquireNewAsync(
        string instanceId,
        string claimantId,
        TimeSpan leaseDuration,
        CancellationToken ct = default)
        => TryAcquireAsync(instanceId, claimantId, leaseDuration, ct);

    /// <summary>
    /// Extends an existing lease held by <paramref name="claimantId"/>.
    /// Returns <c>true</c> when renewal succeeds, <c>false</c> if the lease has expired
    /// or was taken by another node.
    /// </summary>
    /// <param name="instanceId">The workflow execution instance whose lease to renew.</param>
    /// <param name="claimantId">Must match the claimant that originally acquired the lease.</param>
    /// <param name="leaseDuration">New lease duration from now.</param>
    /// <param name="ct">Cancellation token.</param>
    Task<bool> RenewAsync(
        string instanceId,
        string claimantId,
        TimeSpan leaseDuration,
        CancellationToken ct = default);

    /// <summary>
    /// Releases a previously acquired lease so another node can claim the instance.
    /// </summary>
    /// <param name="instanceId">The workflow execution instance to unlock.</param>
    /// <param name="claimantId">Must match the claimant that holds the lease; no-op if it does not.</param>
    /// <param name="ct">Cancellation token.</param>
    Task ReleaseAsync(
        string instanceId,
        string claimantId,
        CancellationToken ct = default);

    /// <summary>
    /// Returns instance IDs that are candidates for resumption by the sweep service:
    /// unclaimed Running instances (server crash) and Suspended instances with expired
    /// waits or accumulated signals.
    /// </summary>
    /// <param name="now">The current timestamp used to evaluate claim expiry and wait timeouts.</param>
    /// <param name="batchSize">Maximum number of IDs to return per sweep pass.</param>
    /// <param name="partitionCount">
    /// Total number of sweep partitions. When greater than 1, only instances whose
    /// ID hashes to <paramref name="partitionIndex"/> are returned, so multiple replicas
    /// can sweep disjoint subsets without contention. Default: <c>1</c> (no partitioning).
    /// </param>
    /// <param name="partitionIndex">
    /// Zero-based index of the caller's partition. Ignored when <paramref name="partitionCount"/> is 1.
    /// Default: <c>0</c>.
    /// </param>
    /// <param name="ct">Cancellation token.</param>
    Task<IReadOnlyList<string>> FindResumableInstanceIdsAsync(
        DateTimeOffset now,
        int batchSize,
        int partitionCount = 1,
        int partitionIndex = 0,
        CancellationToken ct = default);
}

Azure Blob Blob lease API (AcquireLease, RenewLease, ReleaseLease) Native lease duration 15–60s. One blob per instance or one blob for the lock table.

    /// When the underlying DbContext also implements <see cref="IOutboxCapableDbContext"/>,
    /// both writes are committed atomically - guaranteeing at-least-once outbox delivery
    /// even if the process crashes immediately after <c>SaveChangesAsync</c>.

    /// <summary>

    /// <summary>
    /// Streams instances matching <paramref name="filter"/> as an async sequence, yielding pages
    /// lazily to avoid loading the entire result set into memory at once.
    /// Implementations should override this with a native cursor or server-side streaming query
    /// (e.g. Cosmos SDK iterator, EF Core <c>AsAsyncEnumerable</c>, Redis <c>KeysAsync</c>).
    /// </summary>
    /// <param name="filter">Filter and paging base parameters. <c>Skip</c> and <c>Take</c> are
    /// used as the page-size hint; the stream continues until all matching records are exhausted.</param>
    /// <param name="ct">Cancellation token.</param>
    async IAsyncEnumerable<ExecutionInstance> StreamAsync(
        ExecutionQuery filter,
        [System.Runtime.CompilerServices.EnumeratorCancellation] CancellationToken ct = default)
    {
        var pageSize = filter.Take > 0 ? filter.Take : 100;
        var skip = filter.Skip;
        while (true)
        {
            var page = await QueryAsync(new ExecutionQuery
            {
                TenantId = filter.TenantId,
                WorkflowId = filter.WorkflowId,
                WorkflowVersion = filter.WorkflowVersion,
                CorrelationId = filter.CorrelationId,
                Status = filter.Status,
                TagKey = filter.TagKey,
                TagValue = filter.TagValue,
                CreatedAfter = filter.CreatedAfter,
                CreatedBefore = filter.CreatedBefore,
                UpdatedAfter = filter.UpdatedAfter,
                ParentInstanceId = filter.ParentInstanceId,
                IncludeHistory = filter.IncludeHistory,
                Skip = skip,
                Take = pageSize,
            }, ct);
            foreach (var item in page.Items)
                yield return item;
            // Terminate on an empty page as well as on HasMore=false. The empty-page guard is
            // essential for correctness: a QueryAsync implementation that omits Skip on its result
            // makes HasMore (= Skip + Items.Count < TotalCount) read true forever, which would
            // otherwise spin this loop indefinitely once the records are exhausted.
            if (page.Items.Count == 0 || !page.HasMore) yield break;
            skip += pageSize;
        }
    }

    /// under any correlation key, in ascending id order (the store's order, applied consistently) after
    /// <paramref name="afterInstanceId"/>, at most <paramref name="batchSize"/>; none for a <paramref name="batchSize"/>
    /// of 0 or less. Pass the last id of a page as the cursor for the next. The engine uses it to resume every
    /// instance waiting for a circuit that has just closed. The default implementation scans suspended instances
    /// through <see cref="StreamAsync"/>; the built-in stores answer it from an index.
    /// </summary>
    /// <param name="eventName">The event name set on the instances' <see cref="WaitDescriptor"/>.</param>
    /// <param name="afterInstanceId">The cursor: only ids after it are returned; <c>null</c> for the first page.</param>
    /// <param name="batchSize">Maximum number of ids to return.</param>
    /// <param name="ct">Cancellation token.</param>
    async Task<IReadOnlyList<string>> FindSuspendedOnEventAsync(
        string eventName,
        string? afterInstanceId,
        int batchSize,
        CancellationToken ct = default)
    {
        if (batchSize <= 0) return [];
        // A full scan per page: a store with many suspended instances should override this with an index query.
        var ids = new SortedSet<string>(StringComparer.Ordinal);
        await foreach (var instance in StreamAsync(new ExecutionQuery { Status = ExecStatus.Suspended, Take = 200 }, ct))
            if (string.Equals(instance.PendingWait?.EventName, eventName, StringComparison.Ordinal)
                && (afterInstanceId is null || string.CompareOrdinal(instance.InstanceId, afterInstanceId) > 0)
                && ids.Add(instance.InstanceId) && ids.Count > batchSize)
                ids.Remove(ids.Max!);
        return [.. ids];
    }

    /// <summary>
    /// The status and version of each listed instance that exists, in no particular order. The lease renewal service
    /// reads these for every running execution on each pass, so the server-backed built-in stores (SQL, Cosmos,
    /// Redis, Azure Table) answer it without loading full records; the default implementation loads each record.
    /// </summary>
    /// <param name="instanceIds">The instance ids to read; unknown ids are omitted from the result.</param>
    /// <param name="ct">Cancellation token.</param>
    async Task<IReadOnlyList<ExecutionStatusInfo>> GetStatusesAsync(
        IReadOnlyCollection<string> instanceIds,
        CancellationToken ct = default)
    {
        var result = new List<ExecutionStatusInfo>(instanceIds.Count);
        foreach (var id in instanceIds)
            if (await LoadAsync(id, ct) is { } instance)
                result.Add(new ExecutionStatusInfo(instance.InstanceId, instance.Status, instance.Version));
        return result;
    }

    /// Returns all instances whose <see cref="WaitDescriptor.TimeoutAt"/> is at or before
    /// <paramref name="cutoff"/>. Used by the sweep service to resume timed-out waits.
    /// </summary>

    /// in ascending id order (the store's order, applied consistently) after <paramref name="afterInstanceId"/>, at
    /// most <paramref name="batchSize"/>; none for a <paramref name="batchSize"/> of 0 or less. Pass the last id of a
    /// page as the cursor for the next. The sweep uses it to resume a parent whose child finished while nothing could resume it
    /// (the parent's lease was held, or the host was stopping): a queued signal is otherwise only read when the
    /// parent next runs.
    /// </summary>
    /// <param name="afterInstanceId">The cursor: only ids after it are returned; <c>null</c> for the first page.</param>
    /// <param name="batchSize">Maximum number of ids to return.</param>
    /// <param name="ct">Cancellation token.</param>
    Task<IReadOnlyList<string>> FindInstancesWithChildSignalsAsync(
        string? afterInstanceId,
        int batchSize,
        CancellationToken ct = default);

    /// <summary>
    /// Atomically dequeues all pending child signals for <paramref name="parentInstanceId"/>.
    /// Called at the start of each execution cycle to drain accumulated signals.
    /// </summary>
    /// <param name="parentInstanceId">The parent workflow execution instance ID.</param>
    /// <param name="ct">Cancellation token.</param>
    Task<IReadOnlyList<ChildSignal>> DequeueChildSignalsAsync(
        string parentInstanceId,
        CancellationToken ct = default);

    /// <summary>
    /// The pending child signals for <paramref name="parentInstanceId"/>, left queued. The engine reads them to
    /// decide whether a suspended parent should run (the run drains them on entry), so a process stopping in
    /// between loses none. The default implementation dequeues and re-enqueues them, which loses the signals of a
    /// process stopping between the two; the built-in stores read without removing.
    /// </summary>
    /// <param name="parentInstanceId">The parent workflow execution instance ID.</param>
    /// <param name="ct">Cancellation token.</param>
    async Task<IReadOnlyList<ChildSignal>> PeekChildSignalsAsync(
        string parentInstanceId,
        CancellationToken ct = default)
    {
        var signals = await DequeueChildSignalsAsync(parentInstanceId, ct);
        foreach (var signal in signals)
            await EnqueueChildSignalAsync(parentInstanceId, signal, CancellationToken.None);
        return signals;
    }

16. Signal context conventions

When ResumeAsync is called with a signal payload, the engine writes
to reserved context keys before re-entering the execution loop.

Complete reference — all reserved context keys:

Key Written by When Content
$.context._signal Engine (on resume) Any resume carrying a payload Most recent signal payload, overwritten on each resume
$.context._signals Engine (on resume) Any resume carrying a payload Append-only array with one entry per resume: the payload that resumed the instance. Signals below a wait's MinSignalCount accumulate in PendingWait.ReceivedSignals and are not appended
$.context._humanTaskResponse Engine (promoted from the store payload) Human task quorum reached First respondent's validated form values
$.context._humanTaskResponses Engine (promoted from the store payload) Human task quorum reached Array of all respondents' form values (also written when Quorum = 1)
$.context._humanTaskConsensus Engine (promoted from the store payload) Human task quorum reached "unanimous" | "majority" | "any-denied" | "split"; null (NullContextValue) when Quorum = 1

Notes:
- The human task store builds the resume payload with HumanTaskContextKeys.BuildSignalPayload(task): _humanTaskId, _humanTaskResponse, _humanTaskResponses, _humanTaskConsensus. The engine stores the whole payload as _signal (and appends it to _signals), then promotes the three response keys to their own context entries. _humanTaskId is not promoted; the engine uses it to reject a response whose task id differs from PendingHumanTaskId.
- $.context._signal is overwritten on each resume; $.context._signals gets one entry per resume with a payload (only the threshold-reaching signal; earlier signals of a MinSignalCount wait stay in PendingWait.ReceivedSignals).
- Timer nodes do NOT write signal context keys on resume: the sweep service resumes them directly without a signal payload.
- $.context._humanTaskConsensus values: "unanimous" (all responses identical), "majority" (>50% agree), "any-denied" (the majority answer, or with no majority any answer, contains a denial value such as rejected/deny/no/false), "split" (no majority and no denial).

Usage in edge predicates:

$.context._signal.amount               ← field from most recent signal payload
$.context._signals.length              ← how many resumes carried a payload
$.context._humanTaskResponse.decision  ← human decision (Quorum = 1)
$.context._humanTaskConsensus          ← "unanimous" | "majority" | "any-denied" | "split"

See HumanTaskContextKeys static class for typed string constants.

csharp/// <summary>
/// Plugin interface for all node types. Implementations are registered
/// at startup and keyed by NodeType string. The engine dispatches to the
/// correct executor by matching NodeDefinition.Type.
///
/// PERSISTENCE MODEL — all implementors must understand this:
///
/// The engine persists execution state at async boundaries only — specifically
/// when the loop exits due to suspension (wait/human), reaching a terminal
/// state (output/fault/timeout), or host shutdown. It does NOT save after
/// every node. A chain of synchronous nodes runs entirely in memory.
///
/// Consequence: if the server crashes mid-chain, the sweep service reclaims
/// the instance and the engine re-executes from the last SAVED CurrentNodeId,
/// which may be the entry node of the workflow. Every node in the chain
/// re-executes.
///
/// IDEMPOTENCY REQUIREMENT:
///
/// All node executors MUST be safe to re-execute with the same inputs.
///
///   Naturally idempotent (no action required):
///     filter, decision, compute, transform, store — pure functions, no side effects
///     integration (reads/GET) — reading is always safe to repeat
///     query — read-only database access
///     agent — same prompt produces same or acceptable output (note: token cost)
///     timer — builds a WaitDescriptor from a duration expression; re-execution
///       rebuilds the same descriptor (TimeoutAt may shift slightly on re-execution
///       after crash, but this is acceptable — the delay restarts from scratch)
///
///   Must be made idempotent:
///     integration (writes - POST/PUT/PATCH/DELETE) - set idempotencyKeyHeader; the
///       engine sends one generated key per node execution in that header and the
///       server must deduplicate on it (IdempotencyKey is client metadata only)
///     message — use message deduplication on the broker, or IdempotencyKey
///     human — IHumanTaskStore.SaveAsync must be idempotent by (InstanceId, NodeId);
///       if a task record already exists for this execution point, return it
///       rather than creating a duplicate
///     workflow (local) — engine handles: checks for existing child instance
///       keyed by (ParentInstanceId, ParentNodeId) before creating a new one
///
///   Special cases:
///     checkpoint — the only node type that intentionally triggers a mid-loop
///       SaveAsync. Always returns Match. Use before expensive non-idempotent
///       chains to bound the re-execution window on crash recovery.
///

$.engine.* resolution notes

The $.engine namespace is synthesised at resolution time from the live
ExecutionInstance — it is never stored in ContextDictionary.Context.
This means:

  • Read-only — no node can write to $.engine.* via Store()
  • Always current — $.engine.visits.n-review reflects the count at the
    moment Resolve() is called, including the current execution
  • Zero cost — resolved directly from Instance.NodeVisitCounts, no
    additional storage or serialization

The engine implementation of Resolve() checks the path prefix before
dispatching to the context dictionary:

csharp// Pseudocode — engine implementation of Resolve()
public ContextValue? Resolve(string path) => path switch
{
    var p when p.StartsWith("$.engine.visits.") => ResolveVisit(p),
    var p when p.StartsWith("$.engine.")        => ResolveEngineMeta(p),
    var p when p.StartsWith("$.entity")         => Instance.Context.Entity,
    var p when p.StartsWith("$.params.")        => ResolveParams(p),
    var p when p.StartsWith("$.context.")       => ResolveContext(p),
    _ => throw new ArgumentException($"Unrecognised path namespace: {path}")
};

private ContextValue ResolveVisit(string path)
{
    // "$.engine.visits.n-review" → nodeId = "n-review"
    var nodeId = path["$.engine.visits.".Length..];
    var count  = nodeId == "_total"
        ? Instance.NodeVisitCounts.Values.Sum()
        : Instance.NodeVisitCounts.GetValueOrDefault(nodeId, 0);
    return new JsonContextValue { Value = JsonSerializer.SerializeToElement(count) };
}

19. Versioning and concurrency note

ExecutionInstance.Version is a monotonically increasing long (see the class definition in section 1). The state store's save must fail with ConcurrencyException if the stored version does not match the in-memory version. The engine's SaveWithRetryAsync catches it, reloads the instance and, if the reloaded record is terminal (for example cancelled meanwhile), adopts that terminal state and stops; otherwise it copies the fields the execution owns onto the fresh snapshot and saves again.

Implementation note: Cosmos and Azure Table stores may additionally use provider-native ETags for the conditional write; the Version field is still required and must be incremented on every successful save regardless of which mechanism the store uses.

csharp// State store save - required behaviour:
// 1. Compare instance.Version against the persisted version.
// 2. If mismatch -> throw new ConcurrencyException(instance.InstanceId).
// 3. If match    -> write the new state and increment Version.
// SaveWithRetryAsync (EF.FlowEngine/Engine/FlowEngine.cs) makes up to 3 save attempts, reloading between
// them; it returns false when it adopted a terminal state, and a conflict on the third attempt propagates.

/// <summary>
/// Default ICredentialStore — reads structured credential fields from environment variables.
///
/// Environment variable format: FLOWENGINE_CRED_{REF}_{FIELD}
/// where {REF} is the credentialRef with hyphens replaced by underscores, uppercased.
///
/// Example — api-key credential named "product-api":
///   FLOWENGINE_CRED_PRODUCTAPI_TYPE=api-key
///   FLOWENGINE_CRED_PRODUCTAPI_KEY=abc123
///   FLOWENGINE_CRED_PRODUCTAPI_KEYHEADER=X-API-Key
///
/// Example — OAuth2 client credential named "risk-engine":
///   FLOWENGINE_CRED_RISKENGINE_TYPE=oauth2-client
///   FLOWENGINE_CRED_RISKENGINE_CLIENTID=my-client
///   FLOWENGINE_CRED_RISKENGINE_SECRET=my-secret
///   FLOWENGINE_CRED_RISKENGINE_TOKENENDPOINT=https://auth.example.com/oauth/token
///   FLOWENGINE_CRED_RISKENGINE_SCOPE=read:risk
///
/// Example — bearer token named "crm-api":
///   FLOWENGINE_CRED_CRMAPI_TYPE=bearer
///   FLOWENGINE_CRED_CRMAPI_KEY=eyJhbGci...
///
/// Register a custom implementation to use Azure Key Vault, AWS Secrets Manager, etc.
/// </summary>
public sealed class DefaultCredentialStore : ICredentialStore
{
    public Task<Credential?> GetAsync(string credentialRef, CancellationToken ct)
    {
        var prefix = "FLOWENGINE_CRED_"
            + credentialRef.ToUpperInvariant().Replace("-", "_").Replace(".", "_")
            + "_";

        var type = Environment.GetEnvironmentVariable($"{prefix}TYPE");
        if (type == null) return Task.FromResult<Credential?>(null);

        return Task.FromResult<Credential?>(new Credential
        {
            Type          = type,
            Key           = Environment.GetEnvironmentVariable($"{prefix}KEY"),
            Secret        = Environment.GetEnvironmentVariable($"{prefix}SECRET"),
            KeyHeader     = Environment.GetEnvironmentVariable($"{prefix}KEYHEADER"),
            KeyQueryParam = Environment.GetEnvironmentVariable($"{prefix}KEYQUERYPARAM"),
            TokenEndpoint = Environment.GetEnvironmentVariable($"{prefix}TOKENENDPOINT"),
            ClientId      = Environment.GetEnvironmentVariable($"{prefix}CLIENTID"),
            Scope         = Environment.GetEnvironmentVariable($"{prefix}SCOPE"),
        });
    }
}

SqlWorkflowRegistry - database-backed IWorkflowRegistry

InMemoryWorkflowRegistry is for dev/test only. Production deployments should use a persistent registry so workflow definitions survive restarts.

Package

dotnet add package EF.FlowEngine.WorkflowRegistry.Sql

Any EF Core relational provider (SQL Server, PostgreSQL, SQLite). Source: EF.FlowEngine.WorkflowRegistry.Sql/SqlWorkflowRegistry.cs.

Storage

Definitions live in the consumer's DbContext, which implements IFlowEngineStateDbContext and calls modelBuilder.ApplyFlowEngineState() (both in EF.FlowEngine.StateStore.Sql). The table is FlowEngineWorkflowRow (EF.FlowEngine.StateStore.Sql/FlowEngineRows.cs): CompositeKey (primary key, {id}@{version}, max 256), WorkflowId (max 128), Status (integer DefinitionStatus) and Data (the full definition as JSON).

Behaviour

  • SqlWorkflowRegistry<TContext> takes an IDbContextFactory<TContext>.
  • GetAsync: an exact version matches CompositeKey in any status; null or a "2.*" prefix loads the Active rows for the id and picks the highest Version string in application code (there is no version sort column). Warning: the comparison is plain string order (OrderByDescending(d => d.Version)), not semantic-version order, so "1.9.0" sorts above "1.10.0" and stays the "latest" Active version. Until this is fixed, use versions whose string order matches their release order, for example zero-padded segments ("1.09.0", "1.10.0").
  • SaveAsync validates with WorkflowDefinitionValidator.ValidateAndThrow, inserts or updates the row, and throws WorkflowDefinitionMutationException when the existing row is Active.
  • TransitionStatusAsync allows Draft <-> Active only and rewrites the status inside the JSON too; DeleteAsync refuses an Active row.
  • EnsureCreatedAsync (IFlowEngineInitializable) calls Database.EnsureCreatedAsync.

Registration

csharpbuilder.Services.AddFlowEngine()
    .UseWorkflowRegistrySql<MyDbContext>();   // requires IDbContextFactory<MyDbContext>

Migrations

The package ships no migrations. Either let EnsureCreatedAsync create the schema at startup, or generate and apply migrations in your own project for your DbContext.
