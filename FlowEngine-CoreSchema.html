FlowEngine — Core Schema Reference

Reference for ExecutionInstance, IExecutionStateStore, and the foundational interfaces used by the runtime and provider packages.

ExecutionInstance + IExecutionStateStore

This document describes the foundational runtime types and interfaces used by
node executors, state store implementations, and engine services. Changes in
this area affect cross-package compatibility.

1. ExecutionInstance

csharp/// <summary>
/// Represents a single running (or completed/suspended) execution of a
/// workflow definition. Persisted to the state store after every state
/// transition. Immutable fields are set at creation and never changed.
/// </summary>
public sealed class ExecutionInstance
{
    // ── Identity ──────────────────────────────────────────────────────────────

    /// <summary>Globally unique execution identifier. GUID, set at creation.</summary>
    public string InstanceId { get; init; }

    /// <summary>ID of the workflow definition being executed.</summary>
    public string WorkflowId { get; init; }

    /// <summary>
    /// Exact semantic version of the workflow definition at the time this
    /// instance was created. Pinned so definition changes don't affect
    /// in-flight executions.
    /// </summary>
    public string WorkflowVersion { get; init; }

    /// <summary>
    /// Optional correlation identifier supplied by the caller. Used to
    /// associate this instance with an external entity (e.g. OrderId,
    /// ApplicationId). Indexed in the state store for efficient lookup.
    /// </summary>
    public string? CorrelationId { get; init; }

    /// <summary>
    /// Optional parent instance ID when this instance was spawned as a
    /// child (loop iteration, sub-workflow, parallel branch).
    /// Null for root instances.
    /// </summary>
    public string? ParentInstanceId { get; init; }

    /// <summary>
    /// The node ID in the parent instance that spawned this child.
    /// Used to signal the parent when this child completes.
    /// </summary>
    public string? ParentNodeId { get; init; }

    // ── Status ────────────────────────────────────────────────────────────────

    /// <summary>Current execution status. See ExecStatus enum.</summary>
    public ExecStatus Status { get; set; }

    /// <summary>
    /// ID of the node currently being executed (Running) or the node
    /// at which execution is suspended (Suspended).
    /// </summary>
    public string CurrentNodeId { get; set; }

    /// <summary>
    /// For loop/parallel nodes: how many times the current node has been
    /// visited. Checked against WorkflowNode.MaxVisits to prevent infinite
    /// cycles. Keyed by node ID.
    /// </summary>
    public Dictionary<string, int> NodeVisitCounts { get; set; } = new();

    // ── Timing ────────────────────────────────────────────────────────────────

    public DateTimeOffset CreatedAt    { get; init; }
    public DateTimeOffset UpdatedAt    { get; set; }
    public DateTimeOffset? CompletedAt { get; set; }

    /// <summary>
    /// Optional hard deadline for the entire instance. When reached,
    /// the engine transitions Status to TimedOut and executes
    /// WorkflowDefinition.OnDeadline (if defined).
    /// </summary>
    public DateTimeOffset? Deadline { get; init; }

    // ── Context ───────────────────────────────────────────────────────────────

    /// <summary>
    /// The live execution context. Grows as nodes execute.
    /// Three reserved top-level keys:
    ///   $.entity  — the primary entity passed at invocation (read-only)
    ///   $.params  — parameters passed at invocation (read-only)
    ///   $.context — mutable dictionary written by store/compute/integration
    ///               nodes via their storeAs config
    ///
    /// Values are ContextValue — a discriminated union supporting
    /// JSON primitives, document references, and typed entity snapshots.
    /// </summary>
    public ContextDictionary Context { get; set; } = new();

    // ── Async / Wait ──────────────────────────────────────────────────────────

    /// <summary>
    /// Populated when Status = Suspended. Describes what external event
    /// or signal will resume this instance.
    /// </summary>
    public WaitDescriptor? PendingWait { get; set; }

    /// <summary>
    /// For human task nodes: the ID of the open HumanTask record in
    /// the IHumanTaskStore. Null when not at a human node.
    /// </summary>
    public string? PendingHumanTaskId { get; set; }

    // ── Output / Error ────────────────────────────────────────────────────────

    /// <summary>
    /// Set when Status = Completed. The value produced by the terminal
    /// output node.
    /// </summary>
    public ContextValue? Output { get; set; }

    /// <summary>
    /// Set when Status = Faulted or TimedOut. Full error detail including
    /// the node that failed and the exception chain.
    /// </summary>
    public ExecutionError? Error { get; set; }

    // ── Observability ─────────────────────────────────────────────────────────

    /// <summary>
    /// Arbitrary key/value tags for filtering, grouping, and dashboards.
    /// Examples: { "region": "US-EAST", "priority": "high", "tenant": "acme" }
    /// Set at invocation time and/or by store nodes during execution.
    /// Indexed in the state store.
    /// </summary>
    public Dictionary<string, string> Tags { get; set; } = new();

    /// <summary>
    /// Full immutable audit trail. One record appended per node execution.
    /// Never modified after append — only appended to.
    /// </summary>
    public List<NodeExecutionRecord> History { get; set; } = new();

    // ── Distributed Execution ─────────────────────────────────────────────────

    /// <summary>
    /// Opaque identifier of the server instance currently processing this
    /// execution (e.g. hostname + PID, or a startup GUID). Set when a
    /// server claims the instance; cleared when the instance is suspended
    /// or reaches a terminal state.
    ///
    /// The claim mechanism is intentionally abstract — implementations may
    /// use database row locks, Redis SET NX, blob leases, Cosmos ETags,
    /// or any other atomic primitive appropriate to the state store backend.
    /// The IDistributedLockProvider interface (see below) decouples the
    /// locking strategy from the state store.
    /// </summary>
    public string? ClaimedBy { get; set; }

    /// <summary>When the claim was acquired.</summary>
    public DateTimeOffset? ClaimedAt { get; set; }

    /// <summary>
    /// When the claim automatically expires. If a server dies mid-execution
    /// without releasing its claim, the sweep service will reclaim the
    /// instance after this time. Must be renewed periodically by the
    /// executing server via IDistributedLockProvider.RenewAsync.
    /// </summary>
    public DateTimeOffset? ClaimExpiresAt { get; set; }

    // ── Optimistic Concurrency ────────────────────────────────────────────────

    /// <summary>
    /// Monotonically increasing version counter. Incremented by the state store
    /// on every successful save. Used for optimistic concurrency control —
    /// a save that presents a stale Version throws ConcurrencyException.
    /// </summary>
    public long Version { get; set; } = 0;
}

2. ExecStatus

csharppublic enum ExecStatus
{
    /// <summary>Actively executing a node synchronously.</summary>
    Running,

    /// <summary>
    /// Paused at a Wait, Timer, or Human node. Awaiting an external signal,
    /// webhook, elapsed duration, or human task completion. The instance is
    /// persisted and will be resumed by the engine when the trigger fires.
    /// For timer nodes the sweep service resumes automatically when TimeoutAt
    /// elapses — no external call required.
    /// </summary>
    Suspended,

    /// <summary>
    /// Reached a terminal Output node. Output field is populated.
    /// This is a terminal status — no further transitions.
    /// </summary>
    Completed,

    /// <summary>
    /// An unhandled error occurred and no onFailure path was available
    /// or the failure node itself failed. Error field is populated.
    /// Terminal status.
    /// </summary>
    Faulted,

    /// <summary>
    /// Explicitly cancelled by a caller via the engine API.
    /// Terminal status.
    /// </summary>
    Cancelled,

    /// <summary>
    /// The instance-level Deadline was reached before completion,
    /// OR a Wait node's timeout expired with no onTimeout path.
    /// Error field is populated. Terminal status.
    /// </summary>
    TimedOut,

    /// <summary>
    /// A node's MaxVisits limit was reached (cycle guard triggered).
    /// Error field is populated. Terminal status.
    /// </summary>
    CycleDetected
}

              └────┬─────┘                                            │
                   │                                                  │
       ┌───────────┼────────────────────────────┐                     │
       │           │                            │                     │
       ▼           ▼                            ▼                     │
  ┌─────────┐ ┌──────────┐              ┌────────────┐               │
  │Suspended│ │ Faulted  │              │  Completed │               │
  └────┬────┘ │(terminal)│              │ (terminal) │               │
       │      └──────────┘              └────────────┘               │
       │                                                              │
       ├─── ResumeAsync() ────────────────────────────────────────────┘
       │
       ├─── CancelAsync() ──────────► Cancelled (terminal)
       │
       └─── Sweep: deadline/timeout ─► TimedOut (terminal)
                                    ─► CycleDetected (terminal, MaxVisits)

Valid transitions:
  Running   → Suspended     (wait / human / timer node reached)
  Running   → Completed     (output node reached)
  Running   → Faulted       (unhandled error, no failure path)
  Running   → TimedOut      (instance deadline breached)
  Running   → CycleDetected (MaxVisits exceeded on a node)
  Running   → Cancelled     (CancelAsync called)
  Suspended → Running       (ResumeAsync / sweep reclaim / timer elapsed)
  Suspended → Cancelled     (CancelAsync called)
  Suspended → TimedOut      (wait timeout, sweep detected)

Note — timer vs wait on sweep resume:
  timer node + TimeoutAt reached → resumed with Match outcome (delay was the intent)
  wait  node + TimeoutAt reached → resumed with Error outcome (signal didn't arrive)

Terminal states (no further transitions):
  Completed · Faulted · Cancelled · TimedOut · CycleDetected

## 3. ContextValue — discriminated union

```csharp
/// <summary>
/// A value in the execution context. Supports all types nodes can
/// produce or consume. Serializes cleanly to/from JSON for state
/// store persistence.
/// </summary>
[JsonPolymorphic(TypeDiscriminatorPropertyName = "$type")]
[JsonDerivedType(typeof(JsonContextValue),     "json")]
[JsonDerivedType(typeof(DocumentContextValue), "document")]
[JsonDerivedType(typeof(NullContextValue),     "null")]
public abstract class ContextValue { }

/// <summary>JSON-serializable scalar or object value.</summary>
public sealed class JsonContextValue : ContextValue
{
    public JsonElement Value { get; init; }
}

/// <summary>
/// Reference to a binary document (PDF, DOCX, image, etc.) stored
/// externally. The engine passes the reference through context without
/// loading the bytes. Nodes that need the content resolve it via
/// IDocumentStore.
/// </summary>
public sealed class DocumentContextValue : ContextValue
{
    /// <summary>Opaque reference into the document store (URL, blob path, etc.).</summary>
    public string   StoreRef    { get; init; }
    public string   FileName    { get; init; }
    public string   ContentType { get; init; }
    public long     SizeBytes   { get; init; }
    public DateTimeOffset StoredAt { get; init; }
}

/// <summary>Explicit null — distinguishable from absent key.</summary>
public sealed class NullContextValue : ContextValue { }

/// <summary>
/// The top-level context container. Provides typed access to the three
/// reserved namespaces and the mutable context dictionary.
/// </summary>
public sealed class ContextDictionary
{
    public ContextValue?                     Entity  { get; set; }  // $.entity
    public Dictionary<string, ContextValue>? Params  { get; set; }  // $.params
    public Dictionary<string, ContextValue>  Context { get; set; } = new(); // $.context

    // ── $.engine namespace note ──────────────────────────────────────────────
    // The $.engine.* namespace is NOT stored in this dictionary.
    // It is synthesised at resolution time by the concrete IExecutionContext
    // implementation from the live ExecutionInstance fields (NodeVisitCounts,
    // Status, etc.). It is read-only and cannot be written via Store().
    //
    // Paths handled by IExecutionContext.Resolve() dispatcher:
    //   $.entity        → this.Entity
    //   $.params.x      → this.Params["x"]
    //   $.context.x     → this.Context["x"]
    //   $.engine.*      → synthesised (never stored here)

    /// <summary>
    /// Resolve a JSONPath expression against this context.
    /// Supports $.entity, $.params.x, $.context.x
    /// Returns null if path not found.
    /// NOTE: $.engine.* paths are NOT resolved here — they are resolved
    /// by the concrete IExecutionContext.Resolve() implementation which
    /// has access to the live ExecutionInstance. This method handles only
    /// the three stored namespaces.
    /// </summary>
    public ContextValue? Resolve(string jsonPath)
    {
        // Concrete implementation — not a placeholder.
        // Parses namespace prefix and dispatches to Entity, Params, or Context dict.
        // See IExecutionContext in section 18 for the full resolver including $.engine.
        throw new NotSupportedException(
            "ContextDictionary.Resolve is a stub for documentation. " +
            "Use IExecutionContext.Resolve() from node executors.");
    }

    /// <summary>Write a value to $.context[key].</summary>
    public void Store(string key, ContextValue value) => Context[key] = value;
}

4. WaitDescriptor

csharp/// <summary>
/// Describes the condition under which a Suspended instance will be resumed.
/// Persisted as part of the ExecutionInstance.
/// </summary>
public sealed class WaitDescriptor
{
    /// <summary>
    /// The event or signal name the engine listens for.
    /// Examples: "approval.received", "payment.webhook", "training.completed"
    /// </summary>
    public string EventName { get; init; }

    /// <summary>
    /// Value used to correlate an incoming event to this specific instance.
    /// A JSONPath expression evaluated against the context at suspend time.
    /// Example: "$.entity.OrderId" → "ORD-1234"
    /// Stored as the resolved value (not the expression).
    /// </summary>
    public string CorrelationKey { get; init; }

    /// <summary>
    /// Optional. If set, the instance transitions to TimedOut if no
    /// signal arrives by this time. ISO 8601 duration resolved to
    /// absolute DateTimeOffset at suspend time.
    /// </summary>
    public DateTimeOffset? TimeoutAt { get; init; }

    /// <summary>
    /// Node to execute on timeout. If null and TimeoutAt is set,
    /// the instance transitions to TimedOut (terminal).
    /// </summary>
    public string? OnTimeoutNodeId { get; init; }

    /// <summary>
    /// Optional. Minimum number of matching events to accumulate before
    /// resuming. Supports the "accumulate N signals" pattern.
    /// Default: 1 (resume on first matching event).
    /// </summary>
    public int MinSignalCount { get; init; } = 1;

    /// <summary>
    /// Accumulated signals received so far. Engine appends to this
    /// list as matching events arrive. When Count >= MinSignalCount,
    /// the instance resumes. Available in context as $.context._signals.
    /// </summary>
    public List<JsonElement> ReceivedSignals { get; set; } = new();
}

6. DecisionOutcome

csharp/// <summary>
/// The common outcome vocabulary emitted by all node executors.
/// Edges in the workflow definition use these values to determine
/// which branch to follow.
/// </summary>
public enum DecisionOutcome
{
    /// <summary>Condition positively satisfied / operation succeeded.</summary>
    Match,

    /// <summary>Condition explicitly not satisfied (e.g. filter returned 0 results).</summary>
    NoMatch,

    /// <summary>
    /// Could not determine — data was missing, null, or ambiguous.
    /// Distinct from NoMatch: NoMatch means "definitely not", Unknown
    /// means "couldn't tell".
    /// </summary>
    Unknown,

    /// <summary>
    /// An exception or external error occurred during node execution.
    /// Retry policy (if configured) fires before this outcome is emitted.
    /// </summary>
    Error,

    /// <summary>
    /// No specific branch condition matched. Taken by a default/fallback
    /// edge when all other conditions evaluated to NoMatch or Unknown.
    /// </summary>
    Default
}

10. IDistributedLockProvider

csharp/// <summary>
/// Pluggable distributed lock/lease abstraction. Decouples the locking
/// strategy from the state store implementation — any backend can be
/// paired with any lock provider.
///
/// The engine uses this interface to:
///   1. Claim an instance before executing it (prevents duplicate execution)
///   2. Renew the claim while executing (prevents expiry during long work)
///   3. Release the claim when suspending or reaching a terminal state
///   4. Find instances whose claims have expired (crashed server recovery)
///
/// Implementations ship as separate packages and are registered alongside
/// the state store:
///
///   EF.FlowEngine.Locks.Sql          — advisory locks or optimistic UPDATE WHERE
///   EF.FlowEngine.Locks.Redis        — SET NX EX (atomic, TTL-based)
///   EF.FlowEngine.Locks.AzureBlob    — Azure Blob Storage lease API
///   EF.FlowEngine.Locks.Cosmos       — conditional ETag write
///   EF.FlowEngine.Locks.AzureTable   — entity ETag conditional replace
///   EF.FlowEngine.Locks.InMemory     — ConcurrentDictionary (single process only)
///
/// The File state store uses InMemory locks (dev/test only — not safe for
/// multi-server deployments).
/// </summary>
public interface IDistributedLockProvider
{
    /// <summary>
    /// Attempt to acquire an exclusive claim on an instance.
    ///
    /// Must be implemented as a single atomic operation. If the instance
    /// is already claimed by another server with a valid (non-expired)
    /// claim, returns false immediately without blocking.
    ///
    /// The implementation is responsible for writing ClaimedBy,
    /// ClaimedAt, and ClaimExpiresAt to the persisted instance, OR
    /// maintaining these in a separate lock record — whichever is natural
    /// for the backing store.
    /// </summary>
    /// <param name="instanceId">The instance to claim.</param>
    /// <param name="claimantId">
    ///   This server's unique identity. Should be stable for the lifetime
    ///   of the server process (e.g. Environment.MachineName + PID, or a
    ///   startup GUID stored in DI as a singleton).
    /// </param>
    /// <param name="leaseDuration">
    ///   How long the claim is valid before it auto-expires.
    ///   Recommended: 30–60 seconds. Must be longer than the lease
    ///   renewal interval (see RenewAsync).
    /// </param>
    /// <returns>True if the claim was acquired; false if already held.</returns>
    Task<bool> TryAcquireAsync(
        string    instanceId,
        string    claimantId,
        TimeSpan  leaseDuration,
        CancellationToken ct = default);

    /// <summary>
    /// Extend the claim expiry. Called by the engine's heartbeat service
    /// every leaseDuration/2 while the instance is actively executing.
    ///
    /// Returns false if the claim has already expired (another server may
    /// have reclaimed the instance). The engine must treat a false return
    /// as a fatal condition for that execution — stop processing, do not
    /// save state.
    /// </summary>
    Task<bool> RenewAsync(
        string    instanceId,
        string    claimantId,
        TimeSpan  leaseDuration,
        CancellationToken ct = default);

    /// <summary>
    /// Explicitly release the claim. Called when the instance is saved
    /// in a Suspended or terminal state. After release, any server can
    /// claim the instance.
    ///
    /// Must be a no-op if the claim has already expired or was claimed
    /// by a different claimant.
    /// </summary>
    Task ReleaseAsync(
        string    instanceId,
        string    claimantId,
        CancellationToken ct = default);

    /// <summary>
    /// Return IDs of instances whose claims have expired (server died)
    /// OR which have no claim and are in a resumable state.
    ///
    /// Called by the background sweep service (typically every 30s).
    /// Results are used to reclaim and resume orphaned instances.
    ///
    /// "Resumable" means:
    ///   - Status = Running with ClaimExpiresAt in the past (crashed server)
    ///   - Status = Suspended with WaitDescriptor.TimeoutAt in the past
    ///   - Status = Suspended with ReceivedSignals.Count >= MinSignalCount
    ///     (signal arrived but push path didn't resume it)
    /// </summary>
    Task<IReadOnlyList<string>> FindResumableInstanceIdsAsync(
        DateTimeOffset now,
        int            batchSize,
        CancellationToken ct = default);
}

Redis SET key claimantId NX PX ttlMs Natural TTL; renew with SET key claimantId XX PX ttlMs. Fast and simple.
Azure Blob Blob lease API (AcquireLease, RenewLease, ReleaseLease) Native lease duration 15–60s. One blob per instance or one blob for the lock table.

16. Signal context conventions

When ResumeAsync is called with a signal payload, the engine writes
to reserved context keys before re-entering the execution loop.

Complete reference — all reserved context keys:

Key Written by When Content
$.context._signal Engine (ResumeAsync) Any signal/resume Most recent signal payload — overwritten on each resume
$.context._signals Engine (ResumeAsync) MinSignalCount > 1 Append-only array of all received payloads
$.context._humanTaskResponse HumanNodeExecutor Human task quorum reached First/only respondent's validated form values
$.context._humanTaskResponses HumanNodeExecutor Quorum > 1 only Array of all respondents' form values
$.context._humanTaskConsensus HumanNodeExecutor Quorum > 1 only "unanimous" | "majority" | "any-denied" | "split"

Notes:
- $.context._signal is overwritten on each ResumeAsync call. For accumulation patterns (MinSignalCount > 1) use $.context._signals which is append-only.
- $.context._humanTaskResponse is distinct from $.context._signal — it contains the validated form values submitted by the human, not the raw signal payload from the HumanTaskStore.
- Timer nodes do NOT write signal context keys on resume — the sweep service resumes them directly without a signal payload.
- $.context._humanTaskConsensus values: "unanimous" (all same decision), "majority" (>50% agree), "any-denied" (at least one denied/rejected), "split" (no clear pattern).

Usage in edge predicates:

$.context._signal.amount               ← field from most recent signal payload
$.context._signals.length              ← how many signals accumulated
$.context._humanTaskResponse.decision  ← human decision (Quorum = 1)
$.context._humanTaskConsensus          ← "unanimous" | "majority" | "any-denied" | "split"

See HumanTaskContextKeys static class for typed string constants.

18. INodeExecutor

csharp/// <summary>
/// Plugin interface for all node types. Implementations are registered
/// at startup and keyed by NodeType string. The engine dispatches to the
/// correct executor by matching NodeDefinition.Type.
///
/// PERSISTENCE MODEL — all implementors must understand this:
///
/// The engine persists execution state at async boundaries only — specifically
/// when the loop exits due to suspension (wait/human), reaching a terminal
/// state (output/fault/timeout), or host shutdown. It does NOT save after
/// every node. A chain of synchronous nodes runs entirely in memory.
///
/// Consequence: if the server crashes mid-chain, the sweep service reclaims
/// the instance and the engine re-executes from the last SAVED CurrentNodeId,
/// which may be the entry node of the workflow. Every node in the chain
/// re-executes.
///
/// IDEMPOTENCY REQUIREMENT:
///
/// All node executors MUST be safe to re-execute with the same inputs.
///
///   Naturally idempotent (no action required):
///     filter, decision, compute, transform, store — pure functions, no side effects
///     integration (reads/GET) — reading is always safe to repeat
///     query — read-only database access
///     agent — same prompt produces same or acceptable output (note: token cost)
///     timer — builds a WaitDescriptor from a duration expression; re-execution
///       rebuilds the same descriptor (TimeoutAt may shift slightly on re-execution
///       after crash, but this is acceptable — the delay restarts from scratch)
///
///   Must be made idempotent:
///     integration (writes — POST/PUT/DELETE) — use IdempotencyKey; the registered
///       IRequestResponseClient deduplicates on the server side
///     message — use message deduplication on the broker, or IdempotencyKey
///     human — IHumanTaskStore.SaveAsync must be idempotent by (InstanceId, NodeId);
///       if a task record already exists for this execution point, return it
///       rather than creating a duplicate
///     workflow (local) — engine handles: checks for existing child instance
///       keyed by (ParentInstanceId, ParentNodeId) before creating a new one
///
///   Special cases:
///     checkpoint — the only node type that intentionally triggers a mid-loop
///       SaveAsync. Always returns Match. Use before expensive non-idempotent
///       chains to bound the re-execution window on crash recovery.
///

$.engine.* resolution notes

The $.engine namespace is synthesised at resolution time from the live
ExecutionInstance — it is never stored in ContextDictionary.Context.
This means:

  • Read-only — no node can write to $.engine.* via Store()
  • Always current — $.engine.visits.n-review reflects the count at the
    moment Resolve() is called, including the current execution
  • Zero cost — resolved directly from Instance.NodeVisitCounts, no
    additional storage or serialization

The engine implementation of Resolve() checks the path prefix before
dispatching to the context dictionary:

csharp// Pseudocode — engine implementation of Resolve()
public ContextValue? Resolve(string path) => path switch
{
    var p when p.StartsWith("$.engine.visits.") => ResolveVisit(p),
    var p when p.StartsWith("$.engine.")        => ResolveEngineMeta(p),
    var p when p.StartsWith("$.entity")         => Instance.Context.Entity,
    var p when p.StartsWith("$.params.")        => ResolveParams(p),
    var p when p.StartsWith("$.context.")       => ResolveContext(p),
    _ => throw new ArgumentException($"Unrecognised path namespace: {path}")
};

private ContextValue ResolveVisit(string path)
{
    // "$.engine.visits.n-review" → nodeId = "n-review"
    var nodeId = path["$.engine.visits.".Length..];
    var count  = nodeId == "_total"
        ? Instance.NodeVisitCounts.Values.Sum()
        : Instance.NodeVisitCounts.GetValueOrDefault(nodeId, 0);
    return new JsonContextValue { Value = JsonSerializer.SerializeToElement(count) };
}

19. Versioning and concurrency note

ExecutionInstance.Version is a monotonically increasing long (see the class definition in section 1). The state store's SaveAsync must fail with ConcurrencyException if the stored version does not match the in-memory version. The engine catches ConcurrencyException, reloads the instance, replays the last node result, and retries the save. This prevents lost updates in multi-host deployments.

Implementation note: Cosmos and Azure Table stores may additionally use provider-native ETags for the conditional write; the Version field is still required and must be incremented on every successful save regardless of which mechanism the store uses.

csharp// State store SaveAsync — required behaviour:
// 1. Compare instance.Version against persisted version.
// 2. If mismatch → throw new ConcurrencyException(instance.InstanceId).
// 3. If match   → write the new state and increment Version.
// The engine's SaveWithRetryAsync catches ConcurrencyException,
// reloads, merges, and retries up to 3 times.

/// 
/// DefinitionStatus lifecycle:
///   Draft  — under construction; cannot be started; GetAsync(id, null) excludes Draft.
///   Active — published; new instances can be started; GetAsync(id, null) returns latest Active.
///
/// Transitions: Draft ↔ Active (bidirectional).
/// Active definitions are immutable — transition back to Draft to edit.
/// StartAsync throws WorkflowNotActiveException for Draft definitions.
/// 
public enum DefinitionStatus { Draft, Active }

/// <summary>Default — ConcurrentDictionary keyed by "id@version".</summary>
public sealed class InMemoryWorkflowRegistry : IWorkflowRegistry
{
    private readonly ConcurrentDictionary<string, WorkflowDefinition> _store = new();

    public Task<WorkflowDefinition?> GetAsync(string id, string? version, CancellationToken ct)
    {
        if (version != null && !version.Contains('*'))
        {
            _store.TryGetValue($"{id}@{version}", out var exact);
            return Task.FromResult(exact);
        }
        // Find latest Active version matching constraint
        var candidates = _store.Values
            .Where(d => d.Id == id && d.Status == DefinitionStatus.Active)
            .OrderByDescending(d => d.Version);
        if (version != null) // wildcard like "2.*"
        {
            var prefix = version.Replace(".*", ".");
            candidates = (IOrderedEnumerable<WorkflowDefinition>)
                candidates.Where(d => d.Version.StartsWith(prefix));
        }
        return Task.FromResult(candidates.FirstOrDefault());
    }

    public Task SaveAsync(WorkflowDefinition definition, CancellationToken ct)
    {
        _store[$"{definition.Id}@{definition.Version}"] = definition;
        return Task.CompletedTask;
    }

    public Task<IReadOnlyList<WorkflowDefinition>> ListAsync(
        string? idFilter, DefinitionStatus? status, CancellationToken ct)
    {
        var q = _store.Values.AsEnumerable();
        if (idFilter != null) q = q.Where(d => d.Id == idFilter);
        if (status   != null) q = q.Where(d => d.Status == status);
        return Task.FromResult<IReadOnlyList<WorkflowDefinition>>(q.ToList());
    }
}

Implementation contract

csharppublic sealed class SqlWorkflowRegistry : IWorkflowRegistry
{
    // Constructor receives IDbContextFactory<WorkflowRegistryDbContext>
    // (registered by UseWorkflowRegistry<SqlWorkflowRegistry>).

    public async Task<WorkflowDefinition?> GetAsync(
        string id, string? version, CancellationToken ct)
    {
        // version == null  → latest Active: WHERE id=@id AND status='Active'
        //                    ORDER BY version_sort_key DESC  LIMIT 1
        // version == "2.*" → WHERE id=@id AND status='Active'
        //                    AND version LIKE '2.%'
        //                    ORDER BY version_sort_key DESC  LIMIT 1
        // version == exact → WHERE id=@id AND version=@version
        //                    (any status — pinned in-flight instances use exact)
    }

    public async Task SaveAsync(WorkflowDefinition definition, CancellationToken ct)
    {
        // UPSERT on (id, version).
        // If a row with this (id, version) exists and status = Active:
        //   throw WorkflowAlreadyPublishedException
        //   — published definitions are immutable; bump the version instead.
        // Draft rows may be overwritten freely.
        // Sets updated_at = UtcNow on every save.
    }

    public async Task<IReadOnlyList<WorkflowDefinition>> ListAsync(

Semver ordering

SQL ORDER BY version DESC is lexicographic and incorrect for semver
("1.10.0" sorts before "1.9.0"). Store a computed sort key:

sql-- Add to schema:
version_sort_key INT NOT NULL
    GENERATED ALWAYS AS (
        CAST(SPLIT_PART(version, '.', 1) AS INT) * 1000000 +
        CAST(SPLIT_PART(version, '.', 2) AS INT) * 1000    +
        CAST(SPLIT_PART(version, '.', 3) AS INT)
    )  -- SQL Server: use a computed column expression equivalent

For portability, computing the sort key in application code before insert is
also acceptable — there will never be enough versions per workflow ID for
this to be a performance concern.
